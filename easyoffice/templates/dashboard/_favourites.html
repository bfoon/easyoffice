{% comment %} templates/dashboard/_favourites.html ==================================== ⭐ The Favourites tab: a grid of tiles for whatever this person pinned. Include ONCE near the top of the dashboard's content block, directly after the page header: {% include 'dashboard/_favourites.html' %} HOW THE TAB SWITCH WORKS ------------------------ The tab strip does not wrap the rest of the dashboard in a container. It marks every element that follows it as the "overview" pane at runtime and toggles those. That matters because supervisor_dashboard.html and admin_dashboard.html both APPEND their own cards after this point via {{ block.super }} — a wrapper div would have to be opened here and closed in three different templates, and the moment a fourth dashboard appeared it would be wrong. Marking siblings adapts to whatever the page turns out to contain. WHERE THE PICKER GETS ITS LIST ------------------------------ From the sidebar that is already on the page — every `.eo-nav-link` in `.eo-nav`. There is deliberately no catalogue of modules anywhere: the sidebar has already applied every permission check, so a link the user cannot see is not in their DOM and cannot be pinned. See the note in apps/dashboard/models.py. {% endcomment %}
